# 🎅 Secret Santa Telegram Bot

Telegram бот для организации игры "Тайный Санта" (Secret Santa).

## 🎄 Возможности

- 👤 **Профили участников** - фото, информация о себе и список желаемых подарков
- 📝 Создание комнат для игры в Тайного Санту
- 🔗 Генерация пригласительных ссылок для участников
- 👥 Поддержка нескольких комнат для одного пользователя
- 🎲 Автоматическая жеребьевка с уведомлениями участников
- 🎁 Просмотр профиля получателя после жеребьевки
- 🔒 Конфиденциальность - каждый участник видит только своего получателя
- 👑 Управление комнатой администратором (создателем)
- ♻️ Возможность перепроведения жеребьевки

## 🚀 Технологии

- **aiogram 3.x** - современный фреймворк для Telegram Bot API
- **PostgreSQL** - надежная реляционная база данных
- **Docker & Docker Compose** - контейнеризация для простого развертывания
- **Python 3.11** - язык программирования

## 📋 Требования

- Docker и Docker Compose
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

## 🛠️ Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <repository_url>
cd tainy_santa_lol
```

### 2. Настройка окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Отредактируйте `.env` и укажите:
- `BOT_TOKEN` - токен вашего бота от BotFather
- `POSTGRES_PASSWORD` - пароль для базы данных (измените на безопасный)

```env
BOT_TOKEN=your_bot_token_here
POSTGRES_PASSWORD=your_secure_password_here
```

### 3. Запуск бота

```bash
docker-compose up -d
```

Бот автоматически:
- Создаст базу данных PostgreSQL
- Выполнит SQL миграции
- Запустит Telegram бота

### 4. Проверка работы

Просмотр логов:
```bash
docker-compose logs -f bot
```

Остановка бота:
```bash
docker-compose down
```

Перезапуск бота:
```bash
docker-compose restart bot
```

## 📱 Использование бота

### Для участников

1. **Начало работы**
   - Отправьте `/start` боту

2. **Заполнение профиля** (рекомендуется)
   - Нажмите "👤 Мой профиль"
   - Нажмите "✏️ Редактировать профиль"
   - Добавьте информацию о себе (интересы, хобби)
   - Загрузите фото
   - Укажите список желаемых подарков
   - Это поможет вашему тайному санте выбрать идеальный подарок!

3. **Создание комнаты**
   - Нажмите "🎄 Создать комнату"
   - Введите название комнаты
   - Получите пригласительную ссылку

4. **Присоединение к комнате**
   - Перейдите по пригласительной ссылке от администратора
   - Или нажмите "🔗 Присоединиться по ссылке" и введите код

5. **Просмотр своих комнат**
   - Нажмите "📋 Мои комнаты"
   - Выберите комнату для просмотра деталей

6. **Узнать своего получателя**
   - После жеребьевки нажмите "🎁 Узнать кому дарить" в комнате
   - Увидите имя получателя, его профиль и список желаний
   - Нажмите "👤 Профиль получателя" для просмотра полной информации
   - Никому не говорите, кому вы дарите подарок! 🤫

### Для администратора комнаты

1. **Приглашение участников**
   - Откройте комнату
   - Нажмите "🔗 Пригласительная ссылка"
   - Отправьте ссылку друзьям

2. **Просмотр участников**
   - Нажмите "👥 Участники" в комнате
   - Увидите список всех участников

3. **Проведение жеребьевки**
   - Дождитесь, пока все участники присоединятся (минимум 2)
   - Нажмите "🎲 Провести жеребьёвку"
   - Подтвердите действие
   - Все участники автоматически получат уведомления

4. **Перепроведение жеребьевки**
   - Если нужно провести жеребьевку заново
   - Нажмите "♻️ Перепровести жеребьёвку"
   - Предыдущие назначения будут удалены

## 🗄️ Схема базы данных

- **users** - пользователи бота (с полями: bio, photo_file_id, wishlist)
- **rooms** - комнаты для игры
- **room_members** - участники комнат (many-to-many)
- **assignments** - назначения Тайного Санты

## 🔒 Безопасность

- Назначения Secret Santa хранятся в зашифрованной базе данных
- Только участник видит своего получателя
- Администратор не видит результаты жеребьевки
- Используйте безопасный пароль для базы данных в production

## 🐛 Разработка

### Локальный запуск без Docker

1. Установите PostgreSQL
2. Создайте базу данных
3. Выполните SQL из `sql/init.sql`
4. Установите зависимости:
```bash
pip install -r requirements.txt
```
5. Настройте `.env` с локальными параметрами БД
6. Запустите бота:
```bash
python -m bot.main
```

### Логирование

Бот использует стандартный модуль `logging` Python. Уровень логирования - INFO.
